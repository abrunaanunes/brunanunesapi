## 📖 Descrição

Esse projeto é uma API REST simples para gerenciar dados de estudantes.  
Faz parte de uma avaliação da disciplina **Arquitetura Java** no Instituto Infnet.  
Possui operações CRUD para a entidade `Student` (criar, ler, atualizar, excluir).

---

## 🛠 Tecnologias

- Java 17  
- Spring Boot  
- Maven
